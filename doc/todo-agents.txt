*todo-agents.txt*  *todo-agents*  TODO tasks linked to Herdr workspaces

Open a Markdown or text file in Neovim inside Herdr:
>
    #### ~/code/api
    - [ ] Fix validation
    - [ ] Add search
<
Press gx on an unchecked task. Herdr creates a worktree and task branch
from the repo's local main branch, starts Codex with an empty composer,
and selects its workspace. Type your instructions in Codex.

The task becomes a herdr:// link to its worktree. Save the file normally.
Press gx on the link to return to the workspace's agent, including when
a review tab is selected. With no running agent, gx opens the workspace.
Start or resume your agent from its shell.

REVIEW
In the task workspace, Ctrl-B then C creates another tab with Herdr's
default keys. With terminal.new_cwd = "follow" (the default), its shell
starts in the same worktree. Run git diff main, git status, or nvim .
Your agent stays in its tab; use your TODO link to return to it.

FOLDERS
Each task belongs to the last folder or Markdown heading above it.
All heading levels work. Paths may be absolute, ~/..., or relative to
the TODO file. A trailing / makes a relative folder name explicit.
Without a folder, use the file's repo or cwd for an unnamed buffer.
Invalid folders and fenced code examples do nothing. Checked tasks cannot
start new agents; their existing links still work.
Local main must exist. The plugin never fetches or pulls.

SHORTCUT
    gx          Create a task workspace or return to its agent.
                Other links use your existing gx mapping.

The mapping is local to Markdown, text, and buffers without a filetype.
There are no Ex commands. Edit checkboxes as ordinary text.

HERDR
Herdr owns terminals, tabs, worktrees, and persistence. Closing Neovim
leaves agents running. The plugin does not delete worktrees or branches,
merge changes, save the TODO file, or send prompts to an agent.
Links contain worktree paths and need no plugin metadata or session scans.
Commands use the calling Herdr session and socket context.

CONFIGURATION
>
    require('todo_agents').setup({
      command = { 'codex' },
      mappings = true,
    })
<
command is an argument array. Set mappings = false for custom keys.
The Lua entry point is require('todo_agents').open().

Requires Neovim 0.10+, Git, Herdr TUI 0.9.5+, and an authenticated agent CLI.
