*todo-agents.txt*  *todo-agents*  Text tasks linked to Codex sessions

Write an ordinary text or Markdown file:
>
    ~/code/api
    - [ ] Fix validation
    - [ ] Add coverage

    ~/code/web
    - [ ] Fix the error screen
<
Each task belongs to the last folder above it. Relative paths are relative
to this file. Without a folder, use the repo containing the file. Each task
has one repo. Reading or editing the file creates no worktrees.

Press gx on a task to create its worktree and open Codex. The task becomes
a Markdown link using the actual Codex session ID. Save the file normally.

SHORTCUT
    gx          Start a plain task or reopen its Codex session link.
                Other links use your existing gx mapping.

This is the only plugin mapping, local to task buffers. Edit checkboxes as
ordinary text. In a terminal, <C-\><C-n> enters normal mode; native <C-^>
(usually Ctrl-6) switches back to the alternate buffer. Enter is unchanged.
Use :vertical TodoAgent to open the task in a split.

LINKS                                                   *todo-agents-links*
>
    - [ ] [Fix validation](codex://<session-id>)
<
Links resume that exact local session, including from another note. While
Codex starts, a temporary codex://task/<task-id> link opens its live terminal.
Session metadata and TODO snapshots live in stdpath('state')/todo-agents.
The full buffer, including unsaved edits, is provided as task context.

WORKTREES
Each task gets its own branch from the selected repo's committed HEAD.
New worktrees live in ~/.todo-agents/worktrees/.
Clean worktrees are removed when the agent exits or Neovim quits normally.
Task branches survive. Reopening recreates the worktree from its branch.
Modified, untracked, ignored files and detached HEAD prevent removal.
:TodoAgentCleanup retries cleanup on a stopped task. Crashes can leave
worktrees behind. Review and merge branches yourself. Completion is manual.

COMMANDS
    :Todo [file]               Open a plan; default is the repo's TODO.md.
    :TodoAgent                 Same as gx on a task.
    :vertical TodoAgent        Open the task in a vertical split.
    :TodoAgentBind {id}        Bind an unbound task to the ID from /status.
    :TodoAgentCleanup          Remove a clean, stopped task worktree.

CONFIGURATION
>
    require('todo_agents').setup({
      command = { 'codex' },
      mappings = true,
    })
<
Set mappings = false for custom keys. The Lua entry point is
require('todo_agents').open(); open(true) uses a vertical split.

Requires Neovim 0.10+, Git, and an authenticated Codex CLI.
